# Ayten & Zaur — Dəvətnamə

Wedding invitation website · 19 Dekabr 2026, Saat 17:00 · Səma Şadlıq Sarayı

## Before uploading
1. Add the music file as `music/gramofon-vals.mp3` (Eugen Doga — Gramofon waltz).
2. (Optional) Set `GUESTBOOK_URL` in `index.html` to collect wishes in one place.

## Publish with GitHub Pages
Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / root → Save.
The site will be live at `https://<username>.github.io/<repo-name>/`.

## Change photos
Replace files in `images/` keeping the same names:
- `cover.jpg` — cover banner
- `hero-1.jpg`, `hero-2.jpg` — envelope photos
- `gallery-1.jpg` … `gallery-3.jpg` — gallery (list is in `GALLERY` inside `index.html`)
